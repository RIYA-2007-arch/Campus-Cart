Slide 04 // Core Security Innovation

The 6-Digit Handover Protocol & Dynamic UPI

Fraud PreventionMutual Verification
Step 01 // Order

Order Initiation

Buyer chooses meetup landmark & checkout mode (Cash on Handover / Direct UPI).

Step 02 // Token

Encrypted OTP

Cryptographic 6-digit OTP is issued and visible only on Buyer's screen.

Step 03 // Inspect

Physical Meeting

Students meet on campus. Buyer physically verifies the textbook or laptop condition.

Step 04 // Verify

Seller Authentication

Seller enters OTP in "My Sales". System marks item SOLD instantly.

Pure Client-Side Dynamic UPI QR Engine

Unlike commercial portals that charge 2% gateway fees, CampusCart generates NPCI upi://pay SVG vector paths natively in memory using Kazuhiko Arase's QR matrix algorithm.

⚡ 100% Offline Generation • Zero Payment Gateway Intermediaries

Reverse Marketplace: "Wanted Board"

Students can post requisitions for out-of-stock items (e.g., "Casio fx-991ES needed for Math-3"). Seniors who possess surplus items can fulfill the request directly.

⚡ Peer Demand-Driven Requisition Matching
